¿Cómo se declara la variable o el contador?
Mediante let se inicializa el contador desde el punto de partida y posteriormete se marca el límite y si va a crecer o decrecer.
for (inicialización; condición; actualización)
for (let i = 0; i < 5; i++) 

¿Cómo se muestra información por consola?
Mediante console.log (); se envuelve el mensaje a mostrar

¿Cómo se delimitan los bloques de código? Comparadlo con la indentación de Python.
Entre llaves se envuelven los fragmentos de código a ejecutar mientas que en Python se identifica mediante tabulación y ";" sirve para separar las instrucciones mientras que en Pyhton se hace mediante el salto de línea.

¿Qué símbolos o palabras cambian respecto al ejemplo en Python?
Java Script usa ";" para separar instrucciones y en Python se usa directamente salto de línea.
No se usa ":" para introducir la instrucción, se escribe entre llaves.
Los comentarios se hacen mediante "//" en vez de "#"

¿Qué decisiones o repeticiones se mantienen? Explicad el algoritmo en castellano, sin usar código.
Para cada elemento desde el valor de inicialización hasta que se deje de cumplir la condición se ejecuta el código dentro de las llaves y se actualiza el valor de inicialización en función de la actualización establecida.
